# Ekantipur scraper — master prompt & selector log

Use this file to brief an AI or developer when changing `scraper.py`, debugging selectors, or extending the scraper.

---

## Goal

Automate extraction from https://ekantipur.com using Playwright (Python, sync API):

1. Open the homepage, dismiss an ad overlay if present (click text "Skip").
2. Visit `/entertainment` and collect the **top 5** entertainment teaser cards.
3. Visit `/cartoon` and collect **one** "cartoon of the day" entry (first matching column).
4. Write UTF-8 JSON to `output.json` (Devanagari preserved: `ensure_ascii=False`).

---

## Output schema (`output.json`)

```json
{
  "entertainment_news": [
    {
      "title": "string",
      "image_url": "string or null",
      "category": "मनोरञ्जन",
      "author": "string or Unknown"
    }
  ],
  "cartoon_of_the_day": {
    "title": "string",
    "image_url": "string or null",
    "author": "string or Unknown"
  }
}
```

---

## Current implementation notes (`scraper.py`)

- Browser: Chromium, `headless=False` by default.
- Navigation: `page.goto(..., wait_until="networkidle")` on home, entertainment, and cartoon URLs. (Modern sites may need `load`/`domcontentloaded` plus explicit waits if this flakes.)
- Overlay: `page.locator("text=Skip")` — click only if `count() > 0`; errors are swallowed with a log message.

## Selectors (verified / in use)

### Entertainment (5 cards)

- Card container:
  `div.category-main-wrapper div.category-wrapper div.category div.category-inner-wrapper`
- Per card:
  - Raw title text: `div.category-description` → `text_content()`; then strip trailing read-time via regex `\d+\s*MINS READ`.
  - Image: `div.category-image img` → attribute `src`.
  - Author: `div.category-description div.author-name p a` → `text_content()`; if missing, use `"Unknown"`.
- Category label in JSON is fixed: `मनोरञ्जन`.

**Past issue:** `article.teaser` returned no nodes; site uses `category-inner-wrapper` layout instead.

### Cartoon (first item)

- Section: `section.cartoon-main-wrapper div.row.g-5 div.col-lg-4` → `.first`
- Description: `.cartoon-description p` → `.first` → `text_content().strip()`
- Parse: split on first `-` into `title` and `author`; if no `-`, author `"Unknown"`.
- Image: `img` inside that column → `src`.

## Commands (local)

- Install deps per `README.md` / `pyproject.toml` (Playwright + `playwright install`).
- Run: `python scraper.py` from project root so `output.json` is written beside the script.
